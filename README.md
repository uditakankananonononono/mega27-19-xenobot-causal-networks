# Computational Xenobot causal networks (research work in progress)

The goal is to test whether measured cell-state interactions explain organism-level behaviors. The current public-data audit finds whole-organism tracks but no confirmed matched, time-resolved cell-level graph plus expression, bioelectric, mechanics and signaling. That makes the flagship cellular causal claim untestable on verified sources so far. See `docs/PREREGISTRATION.md`, `docs/SOURCE_AUDIT.md`, `docs/NEGATIVE_REGISTER.md`.

No wet-lab experiments, causal conclusions, intelligence/memory findings, model wins, or qualifying 50-page paper are claimed.
