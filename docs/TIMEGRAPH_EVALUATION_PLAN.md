# TimeGraph A1/A1C compatibility experiment - planned, not scored

2026-09-26. This is a separate methods-only external benchmark candidate, not a Xenobot study or continuation of the six-organoid hypothesis. Primary paper https://arxiv.org/html/2506.01361v1 and code/data https://github.com/hferdous/TimeGraph , cited KDD 2025 DOI 10.1145/3711896.3737439. The paper's Table 2 supplies graph-recovery TPR/FDR/SHD for FGES, PC, PCMCI+, LPCMCI on 4 observed variables, 500 samples, max lag 2. The A1C downloaded CSV includes X1–X4, U and time despite the paper's description of U as unobserved. Withhold U from algorithm input, retain for ground-truth audit, and establish whether the paper's baselines did the same. If unverifiable, no claim of comparable leaderboard performance.

Before any score: inspect official generator equations and graph semantics. A1C includes contemporaneous X paths (lag 0) and lag-1/2 edges; the project's existing lag-1 mean predictor cannot recover this graph, so first specify an edge estimator and a transparent sparse VAR baseline with matching allowed lags/instantaneous-edge treatment. Evaluate both a deconfounded graph target excluding U-node edges and a declared latent-confounding-aware target if graph labels permit; do not conflate them. Seed/threshold must be selected on a development source, not author-published A1C test outcomes. Reproduce one published baseline from code/config before comparison; compare all three published metrics, not cherry-pick one. Broad datasets and n=500 single realization may yield no meaningful uncertainty; identify independent seeds/replicates or report only descriptive scores. A model that merely beats a published number under a different input/graph convention has not beaten a benchmark.

Do not run the dataset yet: license scope for `Datasets/`, source-ground-truth graph extraction, paper baseline's U input, and published score reproducibility are unresolved. The current stronger endpoint may remain impossible from this repo's RMSE predictor without changing model class. No benchmark beat or biological discovery is established by this plan.
