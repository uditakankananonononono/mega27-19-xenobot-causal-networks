# Pivot 01: constrained cell-neighborhood forecasting (developmental, not a discovery yet)

Prepared 2026-09-26 after structural inspection of all 28 published author-processed Xenobot calcium matrices and independent literature audit. **This is an exploratory amendment after seeing array shapes and one example matrix's standardized values, not a new untouched preregistration.** Original preregistration remains unchanged. No behavioral, genomic, intervention or spatial coordinate outcome is in this dataset. This pivot cannot by itself fulfill the user's cellular causal-mechanism or organism-behavior discovery aim.

## Distinct question
Can the past of other cells predict a focal cell's future calcium activity beyond its own past and a global mean signal, across held-out Xenobots, without crediting batch/global artifacts? This tests a narrow predictive contribution of population state to local cell calcium dynamics, not intelligence, memory, cell-to-cell signaling or causality. Article authors have already studied autocorrelation, functional connectivity, total correlation, temporal information measures and directed transfer; therefore a simple graph/correlation advantage is NOT automatically novel. Novelty demands a stable, interpretable, previously unreported out-of-bot prediction pattern under strict controls and literature review.

## Data boundaries
Use only the official Europe PMC Varley 2025 author supplement (nested MD5 and per-file SHA values in SOURCE_AUDIT/data manifest). The 28 bots are processed GCaMP6s matrices (cell × frame inferred from paper but camera cadence unresolved). No bot shares a verified same-condition independent acquisition batch. Global signal regression in upstream pipeline can induce artifactual anti-correlations; compare results with controls matched for this preprocessing and avoid directed causal language.

## Methods proposal and baselines (freeze before outcome scoring)
- Keep full bot as split unit, never cells/frames across folds. Development set = bots with IDs 01-20, sealed holdout = 21-28 **only as a same-study evaluation**, not external validation; holdout was not untouched in the strict sense because structural scans included all shapes and the first numeric value of bot 01 only. Time-block validation within development bots for hyperparameters, no future leakage, train-only normalization.
- Pre-register target = one-step-ahead within-bot calcium trace prediction per cell. Primary metric = per-bot/per-cell held-out improvement in RMSE versus strongest baseline; bot-level bootstrap interval. Baselines: own-past autoregression, persistence, global-population mean model, degree-/capacity-matched pooled-cell model, and graph model with shuffled/permuted edges. Equal history, training/test windows and parameter budget. Include split by bot and within-bot temporal gap.
- Graph edges cannot be called physical contact because no coordinates are deposited. Learn functional edges solely from training windows; evaluate heldout bot adaptation with history only, fixed adaptation budget. Correlation graph, random rewiring and low-rank pooled population controls. No effective-connectivity or causal-network claim.
- A provisional engineering gate: full data integrity, all baselines, error bars and negative controls on heldout bots. A scientific win additionally needs an independently replicated experiment with the same task, predeclared metric and relevant published comparator. That source is not yet verified, so a same-study predictor win would be explicitly provisional and could fail the user's benchmark/discovery endpoint.
- Any 'minimal graph' is a set of equally predictive sparse graphs across seeds/bootstraps, not an identified necessary biological network. No simulated ablations imply wet-lab loss of function.

## Stop/pivot criteria
If self-history/global baseline matches or beats cross-cell predictor, register the negative and pivot to a new *pre-specified* Xenobot question rather than mining this cohort for a winner. If graph advantage disappears with shuffled edges or preprocessing checks, classify it as representation artifact, not biology. If no independent dataset exists, keep scientific completion open, not fabricate external validation.
