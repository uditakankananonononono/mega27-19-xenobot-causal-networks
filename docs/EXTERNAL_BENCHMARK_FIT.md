# External causal-time-series benchmark fit audit (not yet scored)

Date 2026-09-26. The distinct *methods-only* arm may be tested against pre-existing causal-discovery benchmarks. Candidate primary sources inspected directly:

- CauseMe platform https://causeme.uv.es/ and model list https://causeme.uv.es/models/ : synthetic and hybrid time-series tasks with known causal ground truth; linear VAR, noisy/subsampled and nonlinear variants are listed. The exact train/test API, scoring rules, downloadable files, published submissions, hidden confounder coverage and usage terms have not been inspected, so no comparability or leaderboard claim.
- TimeGraph KDD 2025 source https://github.com/hferdous/TimeGraph (paper DOI 10.1145/3711896.3737439 as cited in source README): repository tree includes `Datasets/A1` (linear) and `Datasets/A1C` (with confounder) CSV time series and generated graph PNGs for variables 4, 6 and 8 and lags 2–4. Its generator source `Codes/a1c.py` explicitly includes a latent U affecting several observed X series. Code license MIT; README says datasets CC BY 4.0, though repository tree uses `Datasets/` while README calls it `data/`, so license scope and citation require verification. The graph labels shown as PNG must be inspected/parsed from authoritative generator equations before scoring; a filename alone is not a ground-truth matrix.
- CausalRivers project source https://github.com/CausalRivers/causalrivers/ offers hydrological multivariate series with geographically grounded network metadata; hydrological processes and evaluation target differ sharply from Xenobot cell coupling, so this would be a transfer stress-test only if ground truth validity is checked.

**Method/task mismatch:** The current own-cell-lag plus population-mean predictor reports per-recording RMSE gains, not an adjacency matrix or edge classifier. It cannot be compared to a causal-graph leaderboard as is. A fair method benchmark requires an explicit directional edge estimator, graph truth, train/test protocol, score metric (precision/recall/AUROC and calibration), competing baselines such as VAR and latent-factor/state-space models, and a reserved external test set. Changing the metric now is a new experiment, not a benchmark victory on the existing organoid work. Benchmark sources are methods calibration, not a new living Xenobot discovery. No direct extracellular intervention or matched behavior in the benchmark.

Open gaps: verify licenses and model ground truth, choose a specific published task and published comparator, version a plan before scoring, reproduce existing baseline, independent result inspection, external biological validation, original Xenobot linkage, and paper.

### Critical TimeGraph A1C source check (2026-09-26)
Fetched the primary generator `https://raw.githubusercontent.com/hferdous/TimeGraph/main/Codes/a1c.py` and one actual CSV `https://raw.githubusercontent.com/hferdous/TimeGraph/main/Datasets/A1C/Gaussian/4%20variable/Lag%202/linear_ts_with_confounder_n500_vars4_lag2.csv`. **The CSV includes the supposedly confounding variable `U` as an explicit column alongside `X1`–`X4` and `time`**. Thus “A1C has a latent confounder” describes the causal generator, but a benchmark that hands this CSV unchanged to the learner does **not** hide U. For a genuinely hidden-common-cause test, predeclare excluding U from features while retaining it only for audit/ground truth. Otherwise false-positive interaction claims caused by *unmeasured* confounding would be invalid. The generator's equations include contemporaneous X paths as well as lags; our lag-1 forecaster cannot compete for full graph recovery without a different model/metric. The broad TimeGraph source should not be counted as a valid matched benchmark yet. Its source README describes `data/` license location while actual tree has `Datasets/`; verify rights before copying or distributing data.
