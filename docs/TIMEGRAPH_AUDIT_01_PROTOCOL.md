# TimeGraph diagnostic graph-recovery protocol, version 1

Prepared 2026-09-26 before running any TimeGraph graph-recovery scores in this project. This is a **diagnostic external methods study**, not a claim of beating the KDD 2025 paper, not a Xenobot biological result, and not the organoid forecast task. Primary paper https://arxiv.org/html/2506.01361v1 ; source repo https://github.com/hferdous/TimeGraph at upstream SHA `4d93403b002664fa55607f308ad0e80623472ded` (verify again before use). Paper Table 2 author-reports TPR/FDR/SHD for FGES/PC/PCMCI+/LPCMCI but does not disclose enough in the inspected text to reproduce inputs/thresholds; A1C CSV exposes U even though paper calls it unobserved. Its data license's path text mismatches actual tree, so do not redistribute upstream CSVs.

## Inputs and graph truth
Select the upstream 4-observed-variable, lag-2, n=500 Gaussian A1 (no confounder) and A1C (with U). Download exact upstream CSVs and hash, never commit raw copies. For A1C withhold U and time from algorithm input; retain U only for auditing hidden-common-cause graph. For A1 use X1-X4 only. Parse the exact upstream generator equations `Codes/a1.py` and `Codes/a1c.py` for visible X_i → X_j edges. For this first diagnostic score **restrict to positive lags 1 and 2** and 4x4x2 edge slots, excluding contemporaneous edges and U edges, and mark this graph target as different from author Table 2's unspecified SHD convention. Also report the excluded contemporaneous and U links, so the task limitation is visible.

## Models and metrics
Baseline: lagged linear VAR(2) by ordinary least squares on all four observed variables with intercept, directed cross-variable lag coefficients tested with a two-sided t statistic (OLS residual variance and (X'X)^-1), Bonferroni alpha .05 across 32 slots. Include own-lag edges in both truth and predictions. Proposed *diagnostic control* (not novel): regress each series on its own two lags first, then compute pairwise other-series lag residual correlations; Bonferroni alpha .05 over 32 slots. This is weaker than VAR conditioning and should reveal false links under common causes. A zero-edge predictor is a reference lower bound. Score visible directed lagged edges by TPR, FDR, SHD (binary Hamming across slots) on A1 and A1C separately. No threshold tuning on A1C results or published Table 2. If model exact tests are unstable, report rather than choose a threshold post hoc. Data n=500 is one realization per condition; no confidence interval from cells/frames or from extra generated seeds in this external-source pass.

Verify computed input hashes, source equations and test output, inspect baseline code availability and published Table 2 protocol. **Do not compare numbers as a published benchmark beat** unless same input columns, graph target including lag-zero/latent representation, thresholding and SHD are demonstrated.
