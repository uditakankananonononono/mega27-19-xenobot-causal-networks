# Evidence gate audit and open work - not a completion statement

Prepared 2026-09-26 by checking source records, current result JSONs, actual test runs and the source repository; this file is a review artifact for the final substantive external critique. It cannot itself supply missing biological evidence.

## Original aim and boundaries
The project's name and scientific goal concern causal cellular networks, adaptation, memory and behavior in *motile basal Xenobots*. The original preregistration `docs/PREREGISTRATION.md` is SHA-locked at `14c102ff6b28ba39615534d2be3438c550f4a184f80961bc4dfc66fb7430baef`. The user requires ten substantive ChatGPT critiques, a fair benchmark win and defensible new discovery, honest negative reporting, and at least 50 pages of body text alone in any final paper. This audit does not turn another construct's observations into Xenobot biology.

## Directly checked source-data gates
- Blackiston movement repo https://github.com/swarm-lab/xenobots/tree/main/rawdata has numbered whole-bot track archives; source audit found one treatment condition per numbered replicate, so unseen-condition generalization cannot be relabeled independent same-condition replication. It lacks cellular physiology paired to tracks.
- Varley 2025 article https://pmc.ncbi.nlm.nih.gov/articles/PMC12520083/ already studies spatial functional calcium connectivity and information integration. Its supplement https://www.ebi.ac.uk/europepmc/webservices/rest/PMC12520083/supplementaryFiles has 28 processed cell x time calcium arrays; no verified per-bot behavior or intervention label in the arrays. The first held-out-bot other-cell-mean forecasting increment was only 0.00000610 RMSE and did not establish new biology.
- Grasso 2025 https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1012149 and source https://github.com/caitlingrasso/bio-connectivity/tree/0581ec7b63b30fb09d70b9d34d8cbbf88e6c4700/data/series_raw : 12 public CSVs from six pre/post-puncture *Xenopus epidermal organoids*. It is a distinct construct. Authors already analyze wound-related functional/information-network differences.
- Original in-vivo reconfigurable-organism XY/time tracks https://github.com/skriegman/reconfigurable_organisms/blob/master/data_analysis/vivo_data.csv are not linked to any per-bot calcium cell matrices; associated primary article https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6994979/fullTextXML .
- Neurobot RNA GEO GSE295614 and primary article https://www.ebi.ac.uk/europepmc/webservices/rest/PMC13185861/fullTextXML have 12 **pooled** RNA libraries, not single-bot or single-cell measures. Group contrasts are prior art.
- June 2026 ATP preprint https://www.biorxiv.org/content/10.64898/2026.06.04.730190v1.full.pdf promises calcium CSV release upon final publication; no usable currently deposited paired source verified. March memory preprint GEO GSE320387 is pooled RNA, not matched cell-calcium behavior data.

## Actual method outcomes
- `results/varley-exploratory-cross-bot.json`: narrow negative other-cell mean forecast, same-study split, no independent external published same-task comparator.
- `results/organoid-method-exploratory.json`: raw pre/post forecast improvement changed in the opposite direction from the locked hypothesis for all six organoids, mean post-pre relative gain -0.0046656. The two-sided sign-flip p=.03125 is not evidence for the specified positive alternative.
- `results/organoid-zscore-posthoc.json`: full-series per-cell z-score diagnostic flips the mean positive but 3/6 signs and p=.84375. It uses future scale and cannot replace the raw outcome.
- `results/organoid-prospective-calibration.json`: separately declared early 25%-calibration-window task gives 2/6 positive, mean -0.029718, p=.1875. It is pre-trained model transfer with adaptation, not direct coupling inference.
- `results/synthetic-calibration.json`: known-ground-truth no-coupling shared latent driver produces larger cross-cell forecast gain than explicit simulated coupling. This is a counterexample to causal specificity, not a biological experiment or external benchmark beat.

## Open gates and stop line
No public matched cellular physiology + spatial cell identity + intervention + same-individual behavior in basal Xenobots; no independent treatment replication for flagship biological inference; no published same-task external model comparator and no benchmark beat; no new validated biological discovery; no 50-page body-text paper. The synthetic method arm lacks a calibrated parameter sweep and realistic causal benchmark with a ground-truth independent biological source. One further substantive external critique remains at this audit's preparation. The existing code and negative logs are progress only. It would be misleading to declare this project done or write a 50-page affirmative discovery paper now. A negative-results/feasibility paper might be possible later if the user explicitly accepts it as an outcome, but the current completion criteria remain unmet.
