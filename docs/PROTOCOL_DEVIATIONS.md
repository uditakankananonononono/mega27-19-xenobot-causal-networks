# Protocol deviations and resolution status

2026-09-26, Pivot 02 raw organoid method. Locked `docs/PIVOT_02_ORGANOID_METHOD.md` says "calculate per-cell RMSE" separately in before and after recordings, then aggregate at organoid level. `src/organoid_method.py` currently flattens all cells x scored frames and computes one pooled RMSE per organoid recording. Although every cell within a given recording has the same number of frames, root-mean-square pooled error is **not** the average of cell-specific RMSEs. Therefore the reported `results/organoid-method-exploratory.json` and dependent post hoc z-score variant use a different estimator than the locked text. Do not label the raw scores strictly preregistered. Preserve all scores and the original SHA-locked protocol unaltered. A correction analysis should explicitly compute each cell's RMSE, average equally over cells within each recording, and retain organoid as inference unit, with a distinct amendment and both result versions shown. Until then the 0/6 sign pattern and p=.03125 are an exploratory implementation outcome with a documented deviation, not clean confirmatory evidence.

A second issue in the locked document: "circularly shifted independently in each source recording" is imprecise. The implementation shifts each cell series by a cell-specific random offset generated from the same seed for every recording; the resulting surrogate excludes focal-cell original series in the mean, but includes a shifted copy of the focal cell's own source trajectory through `(shifted.sum()-shifted_i)`, which is not causal leakage but the spatially uniform surrogate is a weak control. Never read its score as a network-edge null. Related synthetic counterexample remains valid under its own separate protocol.

Open questions: code comments claim circular shifts "No wraparound forecasts" yet `np.roll` wraps at boundaries; the statement is false and should be corrected. Full-recording z-score is a leaky retrospective diagnostic, not future forecasting. Prospective-calibration Pivot 04 was explicitly separate and uses its own pooled RMSE code with a new protocol that did not specify per-cell aggregation, but it still needs clarity about which averaging makes biological sense. No version provides linked Xenobot biology, external benchmark beat, or paper completion.
