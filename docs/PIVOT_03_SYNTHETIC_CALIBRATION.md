# Pivot 03: synthetic calibration of cross-cell mean forecast score

Prepared 2026-09-26 after observing the failed organoid method forecast and **before** running synthetic calibration. This is an expressly post hoc new methods question, not a replacement/reinterpretation of `PIVOT_02` or the locked Xenobot plan. No synthetic result can be called a Xenobot biological discovery.

Hypothesis: A forecaster that adds a lagged leave-one-cell-out population mean to own-cell past should distinguish known positive mean-field coupling from no coupling when training/testing across unseen simulated replicates, but its *apparent* gain must also be tested against shared external drive. If a global unobserved cause yields the same gain, forecast improvement is not diagnostic of cell-to-cell signaling.

Generate equal-size series (64 cells x 240 frames, 24 independent replicates per condition), seed 20260926. Model X_i(t+1)=0.6 X_i(t)+g(mean_{j != i} X_j(t))+h U(t)+eps_i(t); U(t+1)=0.75 U(t)+eta(t). eps, eta independent Gaussian, initial state zero, 40 burn-in frames. Scenarios (g,h): null (0,0), direct mean-field coupling (0.25,0), shared-drive-only (0,0.5). Train separate coefficients on replicate IDs 0-15; test IDs 16-23. Use own-lag ridge vs own-lag+other-cell-mean ridge, fixed penalty 1, score replicate-level RMSE. Compare gain distributions and sign; a working discriminative mechanism indicator would show coupling gain > null **and** coupling gain > shared drive, with the latter a hard falsifier for causal specificity. Publish all three, not only a successful comparison. Intervention/simulation labels are generated in silico and do not verify wet-lab network edges. Analyze robustness to cell count and observation noise only as declared sensitivity; no result shopping.
